# Contributing to Stellar Payment Links Web

## Setup
1. Fork and clone the repository
2. Install dependencies with `npm install`
3. Create `.env.local` from `.env.example`
4. Start local server with `npm run dev`

## Picking Issues
- Start with `beginner` or `good first issue`
- Comment on an issue before implementation
- Keep pull requests scoped to one task

## Coding Guidelines
- Use strict TypeScript
- Prefer small reusable components
- Keep private keys client-side only
- Add manual verification notes in PR description
